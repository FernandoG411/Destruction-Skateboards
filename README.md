# 🛹 Destruction Skateboards - Revista Digital

**Destruction Skateboards** é uma plataforma web moderna no formato de revista digital voltada para a cultura e o universo do skate. O projeto reúne conteúdos, matérias, imagens e novidades do cenário urbano com uma experiência visual fluida e responsiva.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **[Vite](https://vitejs.dev/):** Build tool e ambiente de desenvolvimento ultra-rápido.
* **[TypeScript](https://www.typescriptlang.org/):** Superset JavaScript para tipagem estática e maior segurança no código.
* **HTML5 & CSS3:** Estrutura e estilização moderna da aplicação.

---
